# 📖 Python Contact Book

A simple command-line contact book application built using Python. This project demonstrates the practical use of Python dictionaries for key-value data management and implements core CRUD (Create, Read, Update, Delete) operations.

## 🚀 Features

- **Add a Contact (Create):** Add new contacts with their name, email, and phone number.
- **Search a Contact (Read):** Quickly find a contact's details using their phone number.
- **Update a Contact (Update):** Modify the name or email of an existing contact.
- **Delete a Contact (Delete):** Remove a contact from the book.
- **View All:** Display a list of all saved contacts.
- **Data Validation:** Prevents adding duplicate entries by using the phone number as a unique identifier (key).

## 🛠️ Technologies Used

- **Language:** Python 3.x
- **Data Structure:** Dictionaries (Key-Value pairs)
