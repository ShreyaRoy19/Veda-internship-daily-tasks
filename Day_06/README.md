# Task 6: Generate a Multiplication Table

## Description
This project contains a Python program that accepts a number from the user and generates its multiplication table up to a specified limit. It was created to fulfill the requirements of Task 6 in the Python Programming Track.

## Objective
- Practice using `for` loops.
- Practice creating clearly formatted terminal output.

## Features
- Prompts the user for both the base number and the multiplication limit.
- Uses formatted f-strings for clean, vertically aligned output.
- Automatically loops to run multiple times, satisfying the deliverable of showing output for at least three different numbers.
- Includes basic `try-except` error handling for invalid (non-integer) user inputs.

## How to Run
1. Ensure you have Python installed on your machine.
2. Save the Python script (e.g., `multiplication_table.py`).
3. Run the script from your terminal or command prompt:
   ```bash
   python multiplication_table.py
