# Python Concurrency Comparison

## Description
This project implements small examples of I/O-bound and CPU-bound workloads using `threading`, `multiprocessing`, and `asyncio` to compare their execution results.

## Objective
Understand when different Python concurrency approaches should be used.

## Tools Used
* Python
* `threading`
* `multiprocessing`[cite: 1]
* `asyncio`[cite: 1]

## Deliverables
* Three concurrency implementations (Threading, Multiprocessing, AsyncIO)[cite: 1].
* Execution-time comparison[cite: 1].
* Explanation of suitable use cases[cite: 1].
