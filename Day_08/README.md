# Simple Command-Line To-Do List

A lightweight, menu-driven Python application that allows users to manage their daily tasks directly from the terminal. This project was built to demonstrate the use of lists, loops, conditions, and basic function structuring in Python.

## Features

This application implements fundamental CRUD (Create, Read, Update, Delete) operations:
* **Add a Task (Create):** Append new items to your to-do list.
* **View Tasks (Read):** Display all current tasks with their corresponding numbers.
* **Update a Task (Update):** Modify the description of an existing task using its index.
* **Remove a Task (Delete):** Delete a completed or unwanted task from the list.
* **Input Validation:** Handles invalid menu choices and non-numerical inputs gracefully.

## Prerequisites

* Python 3.x installed on your system.
