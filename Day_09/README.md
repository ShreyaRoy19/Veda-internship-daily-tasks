# Practice Python Lists With Student Records

## Description
This project is a simple Python program designed to develop practical list processing skills. It creates a system that stores student names and marks using parallel lists, demonstrating how to perform core data operations such as searching, identifying extremes (highest/lowest scores), and sorting while keeping associated data synchronized.

## Features
Based on the project requirements, this script includes the following deliverables:
* **Student Record Storage:** Utilizes basic Python lists to hold student names and their corresponding marks.
* **Searching Functionality:** Allows querying a specific student's name to retrieve their exact score.
* **Highest and Lowest Scores:** Uses built-in Python functions to dynamically find and display the top and bottom performers.
* **Synchronized Sorting:** Combines names and marks using `zip()` to ensure data remains accurately paired when sorting the records from highest to lowest score.

## Prerequisites
* Python 3.x installed on your machine. No external libraries are required as the script uses only built-in Python functions.
