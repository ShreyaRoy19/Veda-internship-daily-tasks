## Project Overview
This project applies core Python fundamentals—including data structures (dictionaries and lists), conditional branching, loops, modular functions, and user-input validation—to create a persistent in-memory student record manager[cite: 1].

---

## Key Features
- **Student Record Management:** Add new student records and update existing student names or subject marks[cite: 1].
- **Mark Validation:** Validates that marks entered for any subject fall within the standard `0 - 100` range[cite: 1].
- **Automatic Calculations:** Calculates total marks, percentage, and assigned letter grade upon data entry[cite: 1].
- **Search Capability:** Search for student records dynamically by Student ID or Student Name[cite: 1].
- **Class Performance Summary:** Computes class average percentage and highlights the top and lowest academic performers[cite: 1].
