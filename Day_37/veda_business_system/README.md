# Veda Technology Business & Service Management System

A Python application designed to simulate and manage operations for Veda Technology, covering digital services, internship programs, training modules, customer inquiries, and summary reporting.

## Features
- **Service Management**: Add and search digital services with category and status filtering.
- **Program Management**: Maintain records for training and internship cohorts.
- **Inquiry Management**: Register customer requests and track status resolution.
- **Reporting**: Real-time business summary calculations across active services and pending inquiries.
- **Persistent Storage**: Lightweight JSON file storage with automatic folder generation and error handling.
