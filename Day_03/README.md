# 🔢 Even and Odd Number Checker

> **Veda Technology Python Programming Track - Task 3**
> A Python program that accepts numerical input and determines whether the number is even or odd using conditional statements and the modulus operator.

---

## 📋 Project Overview

**Objective:** Learn conditional statements (`if`, `elif`, `else`) and the practical application of the modulus (`%`) operator.

### Features
*   **Continuous Input:** Processes multiple numbers sequentially using a `while` loop without needing to restart the program.
*   **Negative Number Support:** Correctly evaluates both positive and negative integers (e.g., `-5 is Odd`, `-8 is Even`).[cite: 1]
*   **Input Validation:** Catches non-integer inputs gracefully and prompts the user to enter a valid whole number.[cite: 1]
*   **Clean Exit:** Allows the user to type `exit` to safely terminate the program.[cite: 1]
