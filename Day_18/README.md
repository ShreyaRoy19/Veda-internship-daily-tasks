# Veda Technology - Python Programming Track
## Practice: Exception Handling

### Description
Create a program that safely handles invalid numeric input, division by zero, missing values, and other expected runtime errors.

---

### Objective
Learn practical exception handling using `try`, `except`, `else`, and `finally`.

---

### Deliverables
* Exception-handling demonstration
* At least five handled error cases
* Explanation of each exception

---

### Hints / Best Practices
* Do not use a bare `except` unnecessarily
* Catch specific exceptions where possible
* Give users meaningful error messages

---

### Sample Inputs and Outputs
