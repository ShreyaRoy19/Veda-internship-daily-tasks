# Employee Salary Calculator 💼

A clean, modular, and configurable Python program designed to calculate an employee's gross salary, deductions, and final net salary based on predefined business rules. 

---

## 🚀 Features

* **Configurable Rules:** Easily adjust HRA, DA, tax percentages, and fixed deductions via a central `SALARY_RULES` dictionary without changing the core business logic.
* **Robust Input Validation:** Uses `try-except` blocks and loop validation to safely handle incorrect string inputs or negative numbers.
* **Modular Architecture:** Cleanly separates concerns into dedicated functions for input handling, gross calculations, deductions, and structured formatting.
* **Detailed Breakdown:** Prints a neat, receipt-style summary report of all earnings and deductions.

---

## 🛠️ Requirements

* **Python 3.x** installed on your system. No external libraries or third-party packages are required.
